# Accessible propensity-neighborhood paper

This folder contains a shorter, less dense version of **Behavioral Embeddings and Propensity Neighborhoods for Program Recommendation**. It preserves the propositions, theorem, corollaries, proofs, notation, empirical conclusions, and visual style of the original paper while using plainer explanations and a simpler story arc.

The original paper in `papers/propensity-neighborhoods/` is unchanged.

Compile from this folder with:

```powershell
pdflatex -interaction=nonstopmode -halt-on-error propensity_neighborhood_accessible.tex
pdflatex -interaction=nonstopmode -halt-on-error propensity_neighborhood_accessible.tex
```

The complete compiled paper, including references, must remain at seven pages or fewer.
